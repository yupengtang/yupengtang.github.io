A graduate-level course covering data visualization for exploratory analysis and explanatory communication. Tool-heavy: Tableau Desktop, Tableau Prep Builder, Power BI, Excel, NodeXL, and R. Runs asynchronously online.

## Responsibilities

Graded weekly quizzes, visualization exercises, and dashboard projects with feedback on both technical execution (data joins, calculated fields in Tableau) and design choices (chart type, color, layout). Responded to student questions on Ed Discussions covering data preparation workflows, tool-specific issues, and visualization principles.

Built a privacy-preserving LLM-based Q&A assistant for the course's 100+ students. Developed an end-to-end Python pipeline to transform Ed Discussion data into RAG and SFT datasets (JSONL) with schema-tolerant parsing and metadata traceability, then deployed a retrieval-augmented assistant with configurable embedding backends and GPU-ready evaluation workflows.
