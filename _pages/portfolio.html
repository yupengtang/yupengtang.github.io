TD

PyTorch / TensorDict

pytorch/tensordict ↗

Non-tensor data preserved through gather and shape operations.

Technical details

A NonTensorStack has no tensor leaves, so gather and shape operations such as flip, roll, rot90, narrow, tile, broadcast_to, and reshape rebuilt it as an empty container and the field lost its values. Both now run the operation on a tensor of entry positions and select the stored values from the result, with regression tests.

Upstream PRs #1794 #1796

DS

Hugging Face / Datasets

huggingface/datasets ↗

Streaming split correctness under multi-worker data loading.

Technical details

With more DataLoader workers than shards, IterableDataset.take(n) yielded fewer than n examples and skip(n) skipped fewer, so a validation split held out from a stream could silently flow back into training. Fixed the per-worker counts and added regression tests.

Upstream PR #8695
ADK

Google / Agent Development Kit

google/adk-python ↗

Correct artifact metadata and per-user session isolation for AI agents.

Technical details

Separated internal GCS bookkeeping from user-supplied artifact metadata on reads and writes, preventing stale markers from changing how saved artifacts are loaded. Added regression coverage across GCS, file, and in-memory storage backends. Separately, SqliteSessionService.list_sessions treated an empty user ID as no user and returned every user’s sessions; it now checks for None, with a contract test that runs on every session backend. Both integrated into the main branch via Copybara.

Upstream PRs #7171 #7222

NP

Pyro / NumPyro

pyro-ppl/numpyro ↗

Numerically stable entropy for probabilistic programming.

Technical details

BernoulliLogits.entropy evaluated exp(-logits) directly, so for logits below about −88 in float32 the result and its gradient were NaN for a nearly deterministic distribution. The entropy is even in the logits, so it is now computed at their absolute value in a form that stays finite across the full range.

Upstream PR #2331
