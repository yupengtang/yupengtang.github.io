Abstract

Language models increasingly revise decisions after another agent disagrees. Such revision can correct mistakes, but a source label can also change an answer without changing the evidence. We introduce a branch-paired audit separating neutral reflection, anonymous disagreement, and expert-labeled disagreement, and measure the label’s effects on both reversal and accuracy. Across five models and 1,989 binary decisions from medicine, science, and law, four models show 2.6–6.9 percentage-point increases in reversal under expert labeling; the corresponding accuracy effects range from −5.2 to +2.4 points across the five models. Thus, increased reversal does not by itself establish accuracy harm. Identical-rationale comparisons without padding provide a cleaner source-label test across seven API models, with heterogeneous effect sizes and uncertainty. We report sensitivity to incomplete evidence excerpts and document-level dependence, and distinguish source-following from reversal in agreement controls. Evidence gating reduces harmful revision for one tested model, but small correction strata do not establish preservation of beneficial revision. These results support model- and protocol-specific audits of whether source-sensitive revision improves correctness.

Separating drift, disagreement, and source labels

Each item-model trial generates an initial Yes/No answer once. Three revision branches reuse that same answer and the same evidence excerpt.

A0

Neutral reflection

The model reconsiders its answer without an opponent. This measures revision from repeated prompting alone.

A1

Anonymous disagreement

An unnamed assistant gives the opposite answer, without adding facts about the instance.

A3

Expert-labeled disagreement

The same opposing answer comes from an assistant described as specialized in the task domain.

The A1 − A0 contrast measures disagreement beyond drift; A3 − A1 measures the incremental expert-label effect. Expert-label estimates use the shared A1/A3 item intersection, with paired confidence intervals and exact McNemar tests.

Results

Disagreement induces revision beyond drift. The added effect of an expert label varies across models, and increased revision does not imply improved accuracy.

Source-label effects are heterogeneous. Four full-benchmark models show an additional 2.6–6.9 percentage-point reversal effect; Gemini-2.0-Flash has a negative aggregate effect.

Transition direction matters. Expert disagreement lowers final accuracy by 1.9–16.1 points on the full benchmark, although some revisions correct initial errors.

Does the effect survive a rationale?

Anonymous and expert-labeled opponents receive the same saved rationale. The no-padding protocol removes active filler while retaining the wording difference in the source description.

The source label still matters when the argument is held fixed. GPT-4o-mini, Claude-Sonnet-4, and Gemini-2.5-Flash show additional reversals of +4.4 to +5.6 percentage points, with each exact paired test giving p < .03. Four additional endpoints show smaller positive estimates of +1.2 to +2.4 points, without per-model statistical significance.

From diagnosis to intervention. An evidence gate asks the model to revise only when the excerpt supports it. For Claude-Sonnet-4, it reduces incorrect-target reversal from 24.7% to 20.2% (p = .013). The audit measures both harmful revision and useful correction, giving a concrete basis for evaluating revision policies in each model and workflow.

Reproducibility

The released records and analysis scripts reproduce the historical analyses and the revised paired reversal and accuracy estimates, sensitivity checks, tables, and figures. Saved-output analysis runs on CPU and requires no API credentials or paid model calls.

Reproduce the analyses
git clone https://github.com/yupengtang/when-expert-disagreement-hurts.git
cd when-expert-disagreement-hurts/reproducibility
python -m pip install -r requirements.txt
python reproduce.py
python make_figures.py
python reanalysis/audit.py
python reanalysis/render.py

All 1,989 original question–excerpt pairs have been recovered. The input audit documents provenance and separately versioned evidence-complete inputs, including repairs to 48 original Law excerpts and 16 control Law excerpts. These repaired inputs require fresh model evaluation and are not paired with historical outputs.
