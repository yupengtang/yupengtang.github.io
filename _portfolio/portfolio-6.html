Keeping up with AI research is a real problem. Hundreds of papers drop every week across arXiv, top venues, and Hugging Face. Most researchers either miss important work or spend hours skimming abstracts. I built a system that solves this: a fully autonomous pipeline that publishes a curated daily digest of frontier AI papers, with no human in the loop.

The pipeline runs on a cron schedule via GitHub Actions. Every day at 14:00 UTC, it pulls the top papers from Hugging Face, generates summaries and keyword extraction via GPT-5, formats them as Jekyll posts, commits, and deploys. It has been running autonomously since January 2025, producing 431+ posts without a single manual intervention.

Two GitHub Actions workflows handle orchestration: the first generates content and commits it, the second builds and deploys the Jekyll site. The split keeps content generation failures from blocking deployment of already-committed posts.

Three Content Types

Daily Digest (Mon–Fri)
Top 10 papers from Hugging Face with titles, links, abstracts, and frequency-ranked keywords. 371 digests generated.
Weekly Synthesis (Sat)
LLM-generated report synthesizing the week's research trends across all five daily digests. 40 reports.
Technical Deep Dive (Sun)
Detailed walkthrough of one paper with code examples and practical applications. 20 deep dives.

Technical Details

Paper Fetching

The pipeline hits the Hugging Face Daily Papers API with a date-specific query. If that returns empty (weekends, holidays), it falls back to the general papers endpoint. Papers are ranked and the top 10 are selected.

LLM Integration

Summaries and keywords are generated via the GitHub Models API (openai/gpt-5 endpoint at models.github.ai). Keyword extraction uses a hybrid approach: frequency-based ranking from paper metadata, supplemented by LLM generation when the frequency signal is weak. All API calls include token validation, status checks, and retry logic.

Backfill

A separate workflow supports retroactive generation for missed dates. Running python batch_generate.py --start 2025-01-01 --end 2025-01-31 backfills an entire month of posts, which is how the initial archive was populated.

The entire stack is free: GitHub Actions for compute, GitHub Pages for hosting, Hugging Face API for paper data, GitHub Models for LLM inference. No cloud bill.
